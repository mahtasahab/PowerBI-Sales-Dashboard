# Power BI Sales Analysis Dashboard — AdventureWorksDW

## Project Overview
This project was developed as part of a Power BI training course. It focuses on sales data analysis and visualization using Power BI.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)

## Dataset
AdventureWorksDW

## Project Objectives
- Analyze sales data using interactive visualizations.
- Present business data in a clear and structured dashboard.
- Practice data analysis and reporting skills using Power BI and DAX.
